# SyncSyncAV

Найдите одну и ту же склейку в двух изданиях фильма и узнайте, на сколько кадров или миллисекунд сдвинуть дорожку или субтитры. Приложение работает под Windows x64 с .NET Framework 4.8. При первом запуске пульт выбирает русский для русскоязычной Windows и английский для остальных языков. В **Настройки → Язык** можно сразу переключить интерфейс. Пульт запомнит выбор при следующем запуске.

English: open **Settings → Language** (or **Настройки → Язык**) and choose **English**. You can switch languages while both videos are open.

## Запуск

Распакуйте архив выпуска целиком и запустите `SyncSyncAV.exe`. Два встроенных окна VirtualDub2 откроются автоматически.

1. Перетащите оригинал на A, а другую версию на B. Образ Blu-ray `.iso` (UDF) можно перетащить прямо на A или B и выбрать плейлист. Монтирование не требуется. Для смонтированного или распакованного диска перетащите на нужную панель корень диска (например, `E:\`), папку с каталогом `BDMV` или саму `BDMV`. Пульт откроет список плейлистов: выберите нужный и нажмите **Открыть**. В папке `BDMV` должны быть `index.bdmv` и `PLAYLIST`. В заголовке панели видно имя ISO или папки диска, а под ним — выбранный файл плейлиста. Чтобы вернуться к списку, нажмите **Сменить плейлист…** в заголовке A или B. Список откроется на текущем плейлисте. Можно также открыть конкретный файл `.mpls` напрямую. При переносе двух источников заголовки показывают, какой попадёт в A и какой в B. Кнопки **Открыть видео…** и **Заменить…** открывают системный диалог Проводника с вашими закреплёнными папками в «Быстром доступе». Выделите корень диска или папку **BDMV** и нажмите **Открыть**, чтобы выбрать плейлист. Если вы уже внутри такой папки, нажмите **Выбрать плейлист…**.
2. В каждом окне выберите первый кадр после одной и той же склейки и нажмите **Зафиксировать пару** (K). Общие стрелки перемещают обе версии. При другой монтажной вставке можно сохранить ещё одну точку.
3. В режиме **A = B** смещение равно кадру A минус кадр B. Например, при A=100 и B=148 с частотой 24 кадра/с результат для дорожки из B равен −48 кадрам или −2000 мс. Значок у миллисекунд копирует результат. Кнопка **→ 0** сбрасывает смещение. Щелчок по формуле переключает направление.

**Заменить…** открывает новый файл в выбранной панели. **Убрать** закрывает текущий просмотр. Исходные файлы остаются на диске.

| Клавиши | Действие |
| --- | --- |
| ← / → | Общий шаг при включённой связи |
| A / S, D / F | Подстроить кадр A или B |
| Shift, Ctrl+Shift | Выбранный шаг или удвоенный шаг |
| G / H, O | Ввести номер кадра A / B или смещение |
| K, L | Сохранить пару, переключить связь |
| Ctrl+Z, Ctrl+Y | Отменить, повторить |

## Разработка

Исходники оболочки находятся в `source/`, мост — в `engine/bridge/`. Два закреплённых upstream-коммита и патчи к ним позволяют собирать VirtualDub2 и модуль ввода отдельно. Полный выпуск включает архив для запуска и отдельный архив с исходниками обеих изменённых версий. [Обновление движка и сборка](engine/README.md)

Лицензии собственного кода и SDK находятся в `LICENSE.txt` и `engine/bridge/`. Лицензии VirtualDub2, модуля ввода, шрифтов и библиотек сохранены рядом с соответствующими компонентами.
