# SyncSyncAV

[English](README.md)

SyncSyncAV показывает, на сколько кадров или миллисекунд нужно сдвинуть звук или субтитры из одного издания фильма, чтобы они совпали по времени с видео другого. Откройте оба издания рядом, найдите одну и ту же монтажную склейку и в каждом окне выберите первый кадр после неё. Полученное смещение можно скопировать и применить в редакторе.

## Первый запуск

Для Windows x64 с .NET Framework 4.8 скачайте **SyncSyncAV_0.1.1.zip**, распакуйте архив целиком и запустите `SyncSyncAV.exe`. Оставьте папку `Engine` рядом с программой. При первом запуске интерфейс будет русским в русскоязычной Windows и английским в остальных случаях. Язык можно сменить через **Настройки → Язык**, даже если оба видео уже открыты. [Скачать приложение](https://github.com/ttonych/SyncSyncAV/releases/download/v0.1.1/SyncSyncAV_0.1.1.zip) · [Исходники v0.1.1](https://github.com/ttonych/SyncSyncAV/releases/download/v0.1.1/SyncSyncAV_0.1.1_source.zip)

## Как определить смещение

1. Перетащите в **A** издание, к которому подгоняете дорожку, а в **B** — издание, из которого её берёте.
2. В каждой панели найдите первый кадр после одной и той же склейки. Нажмите **Зафиксировать пару** (`K`). Стрелками `←` и `→` пройдите несколько кадров в обеих версиях, чтобы проверить совпадение.
3. В режиме **A = B** пульт показывает разность «кадр A минус кадр B». Например, если склейка в A на кадре 100, а в B на кадре 148, при 24 кадрах/с разница составит **−48 кадров, или −2000 мс**. Чтобы совместить дорожку из B с картинкой A, сдвиньте её на две секунды раньше.
4. Нажмите значок копирования рядом с миллисекундами. Щелчок по формуле переключает знак и сохраняет выбранные кадры. Кнопка **→ 0** обнуляет смещение. Если в одном издании есть дополнительная сцена, сохраните ещё одну пару на склейке после неё.

## Как открыть Blu-ray

| Что у вас есть | Что сделать в A или B |
| --- | --- |
| Образ Blu-ray ISO (UDF) | Перетащите сам файл `.iso` на панель и выберите плейлист. Ручное монтирование не требуется. |
| Диск или распакованная копия | Перетащите корень диска, папку, содержащую `BDMV`, или саму папку `BDMV`. Внутри `BDMV` нужны `index.bdmv` и каталог `PLAYLIST`. |
| Уже известный плейлист | Откройте нужный файл `.mpls` напрямую. |

Через **Открыть видео…** или **Заменить…** можно выделить папку диска или `BDMV` в Проводнике и нажать **Открыть**. Если вы уже внутри, нажмите **Выбрать плейлист…**. Имя источника и выбранный плейлист видны в заголовке панели. Кнопка **Сменить плейлист…** снова открывает список на текущем плейлисте.

При переносе двух источников заголовки показывают, какой попадёт в A и какой в B. **Убрать** закрывает просмотр в выбранной панели и сохраняет исходный файл на диске.

## Клавиши

| Клавиши | Действие |
| --- | --- |
| `←` / `→` | Шаг назад / вперёд в обеих связанных панелях |
| `A` / `S`, `D` / `F` | Шаг назад / вперёд только в A или только в B |
| `Shift`, `Ctrl+Shift` при шаге | Выбранный крупный шаг или удвоенный крупный шаг |
| `G`, `H`, `O` | Ввести кадр A, кадр B или смещение |
| `K`, `L` | Сохранить пару кадров или переключить связь |
| `Ctrl+Z`, `Ctrl+Y` | Отменить или повторить действие |
