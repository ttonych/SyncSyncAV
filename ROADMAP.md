# SyncSyncAV roadmap

[Русский](ROADMAP.ru.md) · [Changelog](docs/en/CHANGELOG.md)

## Starting point — v0.1.0

The first public release lets you open two editions, find a matching frame, save a sync point and copy the offset. For Blu-ray sources, you can select and change playlists from an ISO, a disc root or a BDMV folder. The application and its corresponding sources are available as two archives. [v0.1.0 release](https://github.com/ttonych/SyncSyncAV/releases/tag/v0.1.0)

## Ready for the next release

The packager puts both guides next to `SyncSyncAV.exe`. Readers can switch between `README.md` and `README.ru.md` offline.

## Proposals for discussion

| Proposal | How to check the result |
| --- | --- |
| Work through an example where one edition contains an extra scene | Using two pairs of frames, one before the insertion and one after it, a reader can calculate and verify the two different offsets. |
| Choose the next Blu-ray test from a reproducible user report | Record how the source was opened, the chosen playlist, the expected frame and the observed frame. If reproducible, build a small test using a synthetic disc. |

Priorities and the contents of the next release are open for discussion.
