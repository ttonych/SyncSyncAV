# Планы SyncSyncAV

[English](ROADMAP.md) · [История выпусков](docs/ru/CHANGELOG.md)

## Отправная точка — v0.1.0

В первом публичном выпуске можно открыть два издания, найти совпадающий кадр, сохранить точку синхронизации и скопировать смещение. Для Blu-ray работают выбор и смена плейлиста из ISO, корня диска и папки BDMV. Приложение и соответствующие исходники доступны двумя архивами. [Релиз v0.1.0](https://github.com/ttonych/SyncSyncAV/releases/tag/v0.1.0)

## Подготовлено к следующему выпуску

Упаковщик кладёт рядом с `SyncSyncAV.exe` оба руководства. Из `README.ru.md` можно перейти в `README.md` и обратно без подключения к сети.

## Предложения для обсуждения

| Предложение | Как проверить результат |
| --- | --- |
| Разобрать пример с дополнительной сценой в одном издании | По двум парам кадров, до и после вставки, читатель сможет вычислить и проверить два разных смещения. |
| Выбрать следующий тест Blu-ray по воспроизводимому пользовательскому примеру | Зафиксировать способ открытия, выбранный плейлист, ожидаемый и фактический кадры. Если случай воспроизводится, сделать небольшой тест с синтетическим диском. |

Порядок этих предложений и состав следующего выпуска предстоит согласовать.
