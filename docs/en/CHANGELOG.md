## v0.1.0 — 11 November 2026

First public release for Windows x64.

- Two panes for frame-by-frame comparison. Save a matching pair, step through linked videos and copy an offset in frames or milliseconds.
- Open video files and Blu-ray sources from an ISO, disc root, BDMV folder or MPLS file. The header shows the source and active playlist. Change playlists while the source is open.
- Russian and English interfaces. Switch languages with both videos open.
- The manual GitHub Actions build passed 86 checks. The release includes two assets, the application and the corresponding sources with the modified VirtualDub2 host and input plugin.
