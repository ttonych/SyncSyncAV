## v0.1.0 — 11 ноября 2026

Первый публичный выпуск для Windows x64.

- Две панели для покадрового сравнения. Сохраните совпадающую пару, перемещайтесь по связанным видео и копируйте смещение в кадрах или миллисекундах.
- Открытие видео и Blu-ray из ISO, корня диска, папки BDMV или файла MPLS. Источник и активный плейлист видны в заголовке. Плейлист можно сменить, пока источник открыт.
- Русский и английский интерфейсы. Язык можно переключить при открытых видео.
- Ручная сборка на GitHub Actions прошла 86 проверок. В релизе два вложения — приложение и исходники с доработанными VirtualDub2 и модулем ввода.
